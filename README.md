# Crisis Control System

Smart Emergency Fuel, Utility and Emergency Resource Management System

## Project Description

Crisis Control System is a web-based crisis-time fuel, utility, and emergency resource management system for Bangladesh.

The system manages:

- User registration and login
- Fuel distribution
- Fuel pump stock
- Vehicle owners
- Emergency vehicles
- Apartment generator diesel
- Route-based fuel planning
- Payments
- QR-based fuel collection
- Authority monitoring
- Transparency reports

## Technology Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- REST API
- QR Code
- bKash and Cash Payment
- Map-Based Services
